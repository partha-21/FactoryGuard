FactoryGuard

When a release goes bad, we notice and roll it back.

FactoryGuard watches a factory monitoring app after every deployment. If sensor data stops flowing, it records the incident and restores the last version that worked.

  1. Create an account. Everything starts at zero.
  2. Start monitoring. A healthy v1.0 is deployed from scratch.
  3. Deploy v1.1. Watch the rollback happen by itself.
